# Autonomous Fake Profile Detection Platform (v2.1.2)

End-to-end multi-modal AI platform for real-time fake account detection, SHAP explainability, continual learning, and MLOps governance.

## Benchmarks (v2.1.2)
- **Adversarial Meta-Ensemble:** 97.39% Combined Accuracy | 94.78% Clean | 100.00% Adversarial | 100.00% Precision | 0.9976 ROC-AUC | 0.233 ms
- **Continual Learner (SGD):** 93.04% Combined Accuracy
- **XGBoost (Multi-Modal):** 83.48% Combined Accuracy

## Run Locally
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
